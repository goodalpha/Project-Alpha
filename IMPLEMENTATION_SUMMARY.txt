FEATURES TESTED
================================================================================

FEATURE ENGINEERING (test_features.py)

Lookahead Bias Prevention:
- Momentum on date T uses only data ≤ T (not T+1...T+5)
- Forward return targets are properly shifted for point-in-time safety
- Last 5 dates have NaN targets (no future prices)

Feature Calculations:
- Momentum computed from past prices (5, 10, 21, 63, 126, 252 day windows)
- Volatility annualized (std × √252) with rolling 21-day window
- Vol differs across stocks (not constant)

Cross-Sectional Transformations:
- Z-score per date: mean ≈ 0, std ≈ 1
- Clipping at ±3.0: removes outliers
- Sector neutralization: sector means ≈ 0
- Rank normalization: values in [-0.5, 0.5]

Target Computation:
- Forward returns correctly computed (T+5 price / T price)
- Excess returns = stock return - benchmark return
- Vol-adjusted returns have lower variance

Macro Features:
- Forward-fill to daily frequency (from monthly)
- VIX regimes properly ordered by quantile

BACKTESTING (test_backtest.py)

Portfolio Construction:
- Weights sum to 1.0 (long-only)
- Equal weights: 1/n per position
- Vol-parity: inverse weighted by volatility

Constraints:
- Position cap (5% max): enforced on all holdings
- Sector cap (30% max): enforced per sector
- Capping reduces concentration

Transaction Costs:
- Zero turnover → zero cost
- High turnover creates positive costs
- Cost scales linearly with turnover amount

Signal Processing:
- Equal signals → equal weights
- Ranking preserves signal order
- Top-N selection selects exactly top N%

Risk Management:
- Regime multipliers reduce exposure:
  - Regime 0: 1.0x exposure
  - Regime 1: 0.75x exposure (stress)
  - Regime 2: 0.50x exposure (high stress)
- Drawdown halt at 15%: exposure → 0

Performance Metrics:
- Sharpe ratio: (mean return / std) × √252
- Max drawdown: largest peak-to-trough decline
- Total return: cumulative product of (1+r)
- Win rate: fraction of positive days

Information Coefficient:
- Perfect ranking → IC = 1.0
- Inverse ranking → IC = -1.0
- Random predictions → IC ≈ 0
- Rank IC (Spearman): similar to IC for smooth data
- ICIR = mean IC / std IC
