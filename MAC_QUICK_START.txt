A) Generate Trading Signals
   $ python3 tradingview_strategy_optimizer.py
   → Shows top 10 recommended stocks to buy

B) Run Live Scraper (monitors TradingView every 5 min)
   $ python3 tradingview_scraper.py &
   → Tracks your positions and P&L automatically

C) View Dashboard (open browser to http://localhost:8501)
   $ python3 -m streamlit run dashboard.py
   → Shows real-time portfolio, P&L, risk metrics

D) Train Model (after 8 hours of trading)
   $ python3 tradingview_model_trainer.py
   → Validates signals, trains improved model

TROUBLESHOOTING
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

"chromedriver not found"
  → brew install chromedriver
  → chromedriver --version (should show version)

"ModuleNotFoundError: No module named 'selenium'"
  → pip install -r requirements.txt
  → python3 -c "import selenium" (should work)

"Permission denied"
  → sudo chmod +x /usr/local/bin/chromedriver
  → chmod 600 .env

"Port already in use" (for Streamlit)
  → Kill existing: kill -9 $(lsof -t -i :8501)
  → Or use different port: streamlit run dashboard.py --server.port 8502
